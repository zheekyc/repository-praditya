LEVEL 4 - SCIENTIFIC CALCULATOR

Penjelasan Program Scientific Calculator

Scientific Calculator merupakan pengembangan aplikasi kalkulator yang digunakan untuk melakukan perhitungan matematika dasar maupun matematika tingkat lanjut. Program ini dibuat menggunakan HTML sebagai struktur halaman, CSS sebagai desain tampilan, dan JavaScript sebagai pengolah logika serta proses perhitungan.

Kalkulator ini merupakan penerapan pembelajaran Logika Algoritma yang menggabungkan input, proses, dan output. Pengguna memasukkan angka atau ekspresi matematika, kemudian JavaScript memproses perhitungan sesuai urutan prioritas operasi matematika dan menampilkan hasilnya pada layar kalkulator.

Fitur dan Tingkatan Kalkulator

  • Level 1: Operasi matematika dasar, seperti penjumlahan, pengurangan, perkalian, dan pembagian.
  • Level 2: Pengembangan input, penghapusan angka, dan pengelolaan ekspresi perhitungan.
  • Level 3: Pengembangan tampilan interaktif, pengolahan ekspresi, serta fitur tambahan pada kalkulator.
  • Level 4: Fungsi matematika saintifik, meliputi sin, cos, tan, akar kuadrat, pangkat, logaritma, logaritma natural, konstanta Pi, konstanta Euler, faktorial, dan tanda kurung.

Fungsi dan Cara Penggunaan

Pengguna dapat memilih mode DEG (Degree) atau RAD (Radian) untuk perhitungan trigonometri. Tombol AC digunakan untuk menghapus seluruh input, DEL untuk menghapus karakter terakhir, dan tombol sama dengan (=) untuk menampilkan hasil perhitungan.

Program juga menyediakan fitur riwayat perhitungan, tombol Ans untuk menggunakan hasil sebelumnya, serta validasi kesalahan seperti pembagian dengan nol, akar bilangan negatif, dan faktorial bilangan yang tidak valid.

Melalui program ini, saya mempelajari penerapan variabel, fungsi, percabangan, perulangan, operator matematika, serta algoritma dalam membangun aplikasi interaktif.
